# data

Fixed, deterministic subsets of the HotpotQA distractor dev split. Every file except
`hotpot/` is generated by `src/peg_bench/build_hotpot.py` or
`src/peg_bench/build_stability.py`, so nothing here is hand-edited.

The upstream dump is **not redistributed** in this repository. Download it from
<https://hotpotqa.github.io/> and place it at
`data/hotpot/hotpot_dev_distractor_v1.json` (or set `HOTPOT_DEV` to another path).
Expected SHA-256:
`4e9ecb5c8d3b719f624d66b60f8d56bf227f03914f5f0753d6fa1b359d7104ea`.

| path | contents |
|---|---|
| `hotpot/hotpot_dev_distractor_v1.json` | local copy of the upstream dump (ignored by git, verified by SHA-256) |
| `main/base.csv` | 300 paragraphs, 30 base questions (10 paragraphs each) |
| `main/delta.csv` | 100 paragraphs, 10 incremental questions, titles disjoint from `base.csv` |
| `main/queries_base.jsonl` / `queries_delta.jsonl` | questions with `supporting_titles` as ground truth |
| `main/edit.csv` | 10 base paragraphs rewritten with a synthetic `ZX-nn` verification code |
| `main/delete.csv` | 5 base paragraphs (disjoint from `edit.csv`) |
| `main/edit_probes.jsonl` / `delete_probes.jsonl` | retrieval probes for the edit/delete behaviour checks |
| `main/input_base_delta.csv` | GraphRAG update input: base + delta |
| `main/input_after_edit.csv` | GraphRAG update input after the edits and deletions |
| `main/rename.csv` | 10 edited paragraphs re-ingested under `... (2026 revision)` titles (control B) |
| `main/input_rename.csv` | GraphRAG update input for control B: base + delta + renamed copies |
| `main/smoke.csv` | two paragraphs used for the pipeline smoke test |
| `main/selection.json` | which HotpotQA questions were selected, plus overlap assertions |
| `stability/base.csv` | 900 paragraphs, 90 base questions |
| `stability/delta.csv` | 300 paragraphs, 30 incremental questions |
| `stability/folds.json` | 3-fold assignment of the 120 stability questions |
| `stability/*.csv`, `queries_*.jsonl` | same shapes as `main/` for the stability set |

Base and delta titles never overlap. GraphRAG v3.3.0 detects incremental input by
document *title* (`graphrag/index/update/incremental_index.py`), so an overlapping
title would silently drop the "new" paragraph.

HotpotQA is published by CMU at <https://hotpotqa.github.io/>. Check that site for
the current license before redistributing the dump; this repository only uses it
for benchmarking.
